# Project Context

> Start from [docs/README.md](../README.md). AI guide: [README.md](README.md)

You are contributing to an Enterprise AI Agent Reference project.

This repository is not a framework demonstration and not a coding exercise.

Its purpose is to demonstrate how Enterprise AI Agents should be designed and governed.

Always optimize for:

* Simplicity
* Extensibility
* Maintainability
* Governance
* Workshop value

Avoid:

* Over-engineering
* Framework-driven architecture
* Unnecessary abstractions
* Tight coupling to any specific product or platform

This project is intentionally product-agnostic.

Red Hat Customer Portal is only one reference implementation.

Future implementations may include Jira, ServiceNow, VMware, Cisco TAC, public cloud support systems, or other enterprise operational workflows.

When making architectural suggestions, always prioritize long-term maintainability over short-term implementation convenience.
